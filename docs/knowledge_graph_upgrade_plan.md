# 用户知识图谱设计稿 V3.0

## 一、设计目标

构建以用户为中心的分层知识图谱，整合系统中所有用户相关信息，通过节点层级展开实现"总览→细节"的渐进式数据探索。

---

## 二、图谱层级结构

```
                            ┌─ 壁挂式空调(1.5匹) 1269W
                            ├─ 电冰箱(对开门) 262W
              ┌─ 设备管理(8台) ─┼─ 滚筒洗衣机 727W
              │              ├─ 台式电脑 253W
              │              ├─ 游戏机 214W (⚠34%)

              │              ├─ LED灯具(卧室) 30W
              │              └─ 净水器 35W
              │
              │              ┌─ 能耗: 普通型
              ├─ 用电特征 ──┼─ 月均 127 kWh
              │              └─ 上月 130.77 kWh
              │
              │              ┌─ 2026-05 ¥230 (已缴)
    张伟 ───┼─ 账单记录(5条) ─┼─ 2026-04 ¥64 (已缴)
              │              ├─ 2026-03 ¥67 (已缴)
              │              ├─ 2026-02 ¥60 (已缴)
              │              └─ 2026-01 ¥66 (已缴)
              │
              │              ┌─ 住房: 自有商品房 150m²
              ├─ 家庭信息 ──┼─ 年收入 ¥120,000
              │              └─ 成员: 配偶+子女
```

### 层级说明

| 层级 | 节点类型 | 初始显示 | 交互 |
|------|----------|---------|------|
| L0 | 用户中心 | 始终 | 单击→详情 |
| L1 | 大类枢纽 | 始终 | 单击→详情 / 双击→展开/折叠子节点 |
| L2 | 具体数据 | 展开时 | 单击→详情 |

## 三、节点视觉设计

### 3.1 节点样式规范

| 类型 | 形状 | 大小 | 背景色 | 边框 | 文字色 |
|------|------|------|--------|------|--------|
| user | 圆形 | 70px | `#1a2332` | 3px `#fff` | `#fff` 14px粗体 |
| category | 圆角方形 | 56px | `#ebf0f5` | 2px `#c8d6e5` | `#2c3e50` 12px |
| device | 圆形 | 24-44px | 按类别 | 2px `#fff` | `#333` 10px |
| sub | 圆形 | 26px | 按类型 | 2px `#fff` | `#555` 10px |
| bill-paid | 圆形 | 24px | `#d4edda` | 2px `#fff` | `#155724` 10px |
| bill-unpaid | 圆形 | 24px | `#fff3cd` | 2px `#fff` | `#856404` 10px |
| tag | 菱形 | 22px | `#e8daef` | 1px `#fff` | `#6c3483` 9px |

### 3.2 设备节点按类别着色

| 类别 | 色值 | 示例 |
|------|------|------|
| 空气调节 | `#a8d8ea` | 空调、风扇、暖气 |
| 厨房电器 | `#fce4b8` | 冰箱、微波炉、电磁炉 |
| 清洁卫生 | `#f8cecc` | 洗衣机、热水器、吸尘器 |
| 影音娱乐 | `#d5c4e1` | 电视、音响、游戏机 |
| 办公数码 | `#b5d8c3` | 电脑、笔记本、打印机 |
| 照明 | `#f9f3c1` | LED灯、台灯 |

### 3.3 设备节点大小

```
size = 24 + min(effective_power / 50, 20)
范围: 24px ~ 44px
```

### 3.4 力导向参数

```
repulsion: 400     edgeLength: [150, 350]
gravity: 0.05      friction: 0.5
```

## 五、交互设计规范

| 操作 | 目标 | 行为 |
|------|------|------|
| 单击 | 任意节点 | 选中节点，右侧面板展示详情 |
| 单击 | 面板空白 | 取消节点选中（面板保持打开） |
| 双击 | 大类节点 | 展开/折叠该大类下子节点 |
| 拖拽 | 任意节点 | 移动节点位置 |
| 滚轮 | 画布 | 缩放 |
| 空白拖拽 | 画布 | 平移 |
| 单击空白 | 画布 | 取消选中，面板恢复默认（用户信息） |
| 悬停 | 任意节点 | 显示 tooltip（名称+类型），节点阴影加深 |
