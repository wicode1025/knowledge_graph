## 一、品牌品质系数体系

### 1.1 品质系数定义

品牌品质系数（Brand Quality Factor, BQF）用于修正电器的基础损坏概率。系数越大，代表该品牌电器品质越好，在同等使用年限下损坏概率越低。

| 品牌等级 | BQF 范围 | 说明 |
|----------|----------|------|
| 旗舰级 | 1.30 ~ 1.50 | 国际高端品牌，用料和工艺顶尖 |
| 一线级 | 1.10 ~ 1.25 | 国内一线品牌，品控成熟 |
| 标准级 | 0.95 ~ 1.05 | 市场主流品牌，品质可靠 |
| 经济级 | 0.75 ~ 0.90 | 经济型品牌，性价比优先 |

### 1.2 修正后的损坏概率公式

```
P_damage(t) = 1 - exp( - (t / (η × BQF))^β )

参数说明：
  t    = 已使用年限（年）
  η    = 该电器类型的特征寿命（年），即 63.2% 产品失效的时间点
         η = lifespan × 1.2
  β    = 威布尔形状参数（β > 1 表示耗损失效期）
  BQF  = 品牌品质系数（Brand Quality Factor）
         BQF > 1 → 寿命延长，损坏更慢（好品牌）
         BQF < 1 → 寿命缩短，损坏更快（差品牌）
```

**计算示例**：冰箱使用6年，寿命12年，β=3.5

| 品牌 | BQF | η_eff = η × BQF | P_damage(6年) |
|------|-----|-----------------|---------------|
| 海尔 | 1.25 | 14.4×1.25=18.0 | 1-exp(-(6/18)^3.5) = 1.8% |
| 美的 | 1.15 | 14.4×1.15=16.6 | 1-exp(-(6/16.6)^3.5) = 2.5% |
| 容声 | 1.10 | 14.4×1.10=15.8 | 1-exp(-(6/15.8)^3.5) = 3.0% |
| 普通品牌 | 1.00 | 14.4 | 1-exp(-(6/14.4)^3.5) = 4.2% |
| 杂牌 | 0.85 | 12.2 | 1-exp(-(6/12.2)^3.5) = 7.6% |

#### 2.1.6 功耗计算公式

```
冰箱月用电量 = 日耗电量 × 当月天数 × 能效系数 × 使用年限老化系数

日耗电量 = 基础日耗电 (由容量决定)

能效系数:
  一级能效: 0.85
  二级能效: 1.00
  三级能效: 1.20

使用年限老化系数:
  aging_factor = 1 + 0.40 × (usage_years / lifespan)²

示例：海尔一级能效对开门冰箱（XL），使用5年
  日耗电 = 1.35度 × 0.85 = 1.15度
  aging_factor = 1 + 0.40 × (5/12)² = 1.069
  月用电量(5月) = 1.15 × 31 × 1.069 = 38.1 kWh
```

#### 2.2.6 功耗计算公式

```
空调月用电量 = 额定功率 × 能效系数 × 日均小时 × 当月使用天数 × 温度系数 × 老化系数

温度系数（设定温度越低，耗电越多）:
  22-24°C: 1.30
  24-26°C: 1.00
  26-28°C: 0.75

老化系数:
  aging_factor = 1 + 0.25 × (usage_years / lifespan)²

示例：格力1.5匹一级能效，夏季每天8小时，温度26°C，使用5年
  额定功率: 850W
  能效系数: 0.85
  月使用天数: 30天（夏季）
  温度系数: 1.00
  aging_factor = 1 + 0.25 × (5/10)² = 1.0625
  月用电量 = 0.85 × 0.85 × 8 × 30 × 1.00 × 1.0625 = 184.2 kWh
```

#### 2.5.5 功耗计算公式

```
储水式热水器月用电量 = 额定功率 × 每次加热时长 × 每天加热次数 × 当月天数 / 1000 × 老化系数

每次加热时长 ≈ 1.5小时（60L加热到75°C）
每天加热次数 ≈ 人数 × 洗澡频率系数

洗澡频率系数:
  每天洗: 1.0
  隔天洗: 0.5
  每周2-3次: 0.35

老化系数:
  aging_factor = 1 + 0.30 × (usage_years / lifespan)²

示例：海尔60L/2200W，3口人，每天洗，每人20分钟，使用3年
  日均加热次数: 3 × 1.0 × 1.5 = 约4.5小时有效加热
  月用电量 = 2200 × 4.5 × 30 / 1000 × (1 + 0.30 × (3/8)²)
           = 297 × 1.042
           = 309.5 kWh
```

## 三、通用公式汇总

### 3.1 损坏概率（威布尔+品牌修正）

```
P_damage(t) = 1 - exp( -(t / η_eff)^β )

η_eff = η × BQF = (lifespan × 1.2) × BQF
```

### 3.2 老化功耗

```
P_effective(t) = P_rated × (1 + aging_rate × (t / lifespan)²)
```
