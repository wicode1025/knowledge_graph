# 知识图谱节点详情面板设计方案

## 设计原则

- 每种节点类型独立设计，信息字段完整
- 缺失字段统一显示 `--`
- 分区分组展示，左标签右数值的表格布局
- 关键状态字段使用颜色标识

---

## 节点类型总览

| 类型 | category | 触发方式 | 说明 |
|------|----------|----------|------|
| 用户中心 | user (center) | 默认显示 | 当前用户的完整画像数据 |
| 设备管理 | category (devices) | 双击大类→单击大类 | 设备汇总统计 + 高风险列表 |
| 用电特征 | category (energy) | 双击大类→单击大类 | 能耗等级、趋势、波动分析 |
| 账单记录 | category (bills) | 双击大类→单击大类 | 账单汇总 + 信用评估 |
| 家庭信息 | category (family) | 双击大类→单击大类 | 家庭成员汇总 + 住房信息 |
| 画像标签 | category (tags) | 双击大类→单击大类 | 用户画像综合评价标签 |
| 设备节点 | device | 双击大类→单击设备 | 单台设备完整运行数据 |
| 能耗标签 | sub (tag) | 双击大类→单击标签 | 能耗等级详情 |
| 月度用电 | sub (kwh) | 双击大类→单击标签 | 月均/总用电详细 |
| 上月用电 | sub (kwh) | 双击大类→单击标签 | 上月用电快照 |
| 账单明细 | sub (bill) | 双击大类→单击标签 | 单月账单完整明细 |
| 家庭成员 | sub (member) | 双击大类→单击标签 | 家庭成员个人信息 |

## 面板容器设计

```
┌─ 节点详情 ────────── × ─┐
│                          │  ← 关闭按钮
│  [节点名称]              │  ← h3 标题
│  [彩色标签/状态标识]     │  ← 节点类型小标签
│                          │
│  ■ 分区标题              │  ← 灰色小字 + 底部分割线
│    标签    值            │  ← 左灰右黑的 row
│    标签    值            │
│                          │
│  ■ 分区标题              │
│    [迷你图表]            │  ← 可选: ECharts mini chart
│    标签    值            │
│                          │
└──────────────────────────┘

面板宽度: 300px
面板高度: 自适应, 最大 content 区 60vh 可滚动
分区间距: 16px
行间距: 6px
标签颜色: #999 (11px)
值颜色: #333 (12px)
分区标题: #888 (11px) uppercase
```
