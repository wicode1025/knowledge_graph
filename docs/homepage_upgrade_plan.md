# 首页设计改进方案

## 现状分析

### 当前页面结构

**首页 (Dashboard.vue)**
- 侧边栏：用户选择、快速筛选、用户预览、标签云
- 主内容区：
  - 统计卡片（4个）
  - 知识图谱可视化
  - 用户画像卡片（基本信息+能耗指标）
  - 用电模式雷达图
  - 用电趋势图

**用户画像页面 (Profile.vue)**
- 用户概览卡片（4个）
- 用电行为分析（时段分布条形图）+ 设备分析（饼图）
- 用户分群 + 相似用户
- 节能建议卡片

---

## 改进目标

将用户画像功能整合到首页，形成统一的用户分析中心：
1. 移除导航栏中的"用户画像"入口
2. 将Profile页面的核心功能整合到Dashboard
3. 增加电费相关分析功能（欠费、违约金、营业额）
4. 优化首页布局，提升用户体验

## 新增分析功能详细设计

### 1. 欠费月份分析

**目的**：分析不同用户类型和用电类型每月的欠费用户数，展示用户的欠费情况随时间的变化趋势

**图表类型**：折线图/面积图

**展示内容**：
- X轴：月份（最近12个月）
- Y轴：欠费用户数
- 多系列线：按用户类型（居民/非居民）或用电类型（一般工商业/大工业/居民生活）区分
- 计算欠费用户数与月份的综合相关系数

**数据来源**：electricity_bill.csv 中的 payment_status='unpaid' 或 'overdue' 的记录

---

### 2. 欠费占比分析

**目的**：分析欠费用户中不同用户类型与用电类型的占比

**图表类型**：饼图 + 堆叠柱状图

**展示内容**：
- 饼图：欠费用户中用户类型占比（居民/非居民）
- 饼图：欠费用户中用电类型占比（一般工商业/大工业/居民生活）
- 堆叠柱状图：不同供电单位的欠费占比对比

**数据来源**：electricity_bill.csv 中 payment_status 为欠费的记录

---

### 3. 违约金分析

**目的**：分析不同用户类型违约金总额随月份的变化趋势

**图表类型**：折线图 + 柱状图

**展示内容**：
- 折线图：不同用户类型的违约金总额趋势
- 柱状图：不同用电类型的违约金总额对比
- 计算违约金与月份的相关系数
- 统计总计违约金金额

**数据来源**：electricity_bill.csv 中的 additional_fee（附加费字段作为违约金参考）

---

### 4. 营业额分析

**目的**：分析营业额的组成，计算不同用户类型电费随月份的变化趋势

**图表类型**：折线图 + 饼图

**展示内容**：
- 折线图：不同用户类型的月度电费收入趋势
- 饼图：总营业额中各用户类型占比
- 计算营业额与月份的相关系数
- 汇总：年度总营业额、各类型占比

**数据来源**：electricity_bill.csv 中的 total_fee（电费金额）字段
