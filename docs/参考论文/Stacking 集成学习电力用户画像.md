摘  要 
在智能电网背景下，提升服务质量显得尤为重要。电费敏感用户通常较为关注
电价、电费、用电等方面的服务。为了提高用户满意度，本课题提出多层源特征
Stacking 集成学习用户画像模型，定位电费敏感用户，辅助电力企业为用户提供针
对性服务。具体研究内容如下： 
（1）电力用户画像数据中包含少量文本类信息，但文本类信息对用户敏感度
较为重要。针对现有用户画像特征处理方法将文本类数值类信息一起处理，导致文
本类信息挖掘不充分的问题，提出一种多层源（多层、多源）特征构造方法，将文
本类与数值类信息进行单独挖掘。利用多层特征构造方法从词语、用户和全局三个
层面构造文本类信息的多层特征；利用多源特征构造方法从工单、通话和电费三个
源头构建用户数值类信息的多源特征。 
（2）电力用户画像特征较为复杂，针对现有用户画像模型尚未综合考量局部、
全局、时序特征和缺失值的问题，提出 Stacking 集成学习两阶段预测模型，利用
Stacking 算法融合各模型的优点。第一阶段利用多层感知器(Multi-Layer Perceptron，
MLP)、卷积神经网络-长短时记忆网络(Convolutional Neural Network - Long Short
Term Memory，CNN-LSTM)和极限梯度提升(Extreme Gradient Boosting，XGB)在全
局、局部、时序特征和缺失值方面的优点对用户敏感度进行预测，第二阶段采用随
机森林(RandomForest，RF)识别出电费敏感用户。 
（3）搭建电力用户画像系统，包括用户管理、数据管理、数据预处理、数据
分析和用户画像五个模块。系统对电费敏感用户进行画像构建，并提供个性化服务。
同时，系统提供用户画像结果矫正和模型校正功能，确保系统的准确性和可靠性。
此外，系统对电力用户的欠费行为和违约金缴纳情况进行分析，通过计算综合相关
系数等方式挖掘潜在信息和关联。系统前端采用layui 框架；后端使用 Django 框
架；借助Pandas进行数据处理和分析；利用TensorFlow构建用户画像模型。 
综上所述，本课题提出的多层源特征 Stacking 集成学习用户画像模型从多层
面、多源头进行特征构造，综合多种模型的优点学习用户复杂的特征，提高了画像
的精度。搭建的电力用户画像系统帮助企业能够更加精准地定位电费敏感用户，了
解电力用户的欠费等情况，提供针对性服务，提高经济效益，推动电力行业的发展。

Abstract 
Abstract 
In the context of the smart grid, enhancing service quality is particularly crucial. 
Electricity-sensitive users generally pay close attention to services related to electricity 
prices, bills, and usage. In order to enhance customer satisfaction, this study proposes a 
multi-layer source feature Stacking ensemble learning user profiling model within the 
framework of the smart grid. This model is designed to identify electricity-sensitive users, 
assisting electric power companies in providing targeted services to their customers. The 
specific research contents are as follows:  
(1) A small amount of textual information is included in the electricity user profiling 
data, with textual data being particularly important for user sensitivity. The existing 
method of handling features in user profiles is combined with textual and numerical 
information, resulting in insufficient exploration of textual data. A multi-layered and 
multi-source feature construction method is proposed to address this issue. Textual 
information is explored separately using the multi-layered feature construction method, 
considering words, users, and global perspectives. Meanwhile, the multi-source feature 
construction method is employed to extract numerical data from sources including work 
orders, call records, and electricity bills. 
(2)The characteristics of electricity user profiles are rather complex. In response to 
the issue of existing user profiling models not comprehensively considering local, global, 
temporal features, and missing values, a two-stage prediction model based on Stacking 
ensemble learning is proposed. The Stacking algorithm is utilized to integrate the 
advantages of various models. In the first stage, the user sensitivity is predicted using 
Multi-Layer Perceptron (MLP), Convolutional Neural Network - Long Short-Term 
Memory (CNN-LSTM), and Extreme Gradient Boosting (XGB), which excel in global, 
local, temporal features, and handling missing values. In the second stage, electricity
sensitive users were identified using the Random Forest (RF) method. 
(3)The electricity user profiling system has been constructed, encompassing five 
core modules: user management, data management, data preprocessing, data analysis, and 
user profile creation. Sensitivity analysis for electricity bills is conducted by the system, 
and personalized services such as SMS notifications are provided. Additionally, the 
system offers functionalities for model testing, model calibration, and user profile result

1.1 研究背景及意义 
电力行业是国家经济发展的重要支撑和基础产业，近年来随着智能电网和信
息化建设的推进，电力行业积累了海量数据[1]。信息过载问题的出现导致了电力企
业在面对这些海量数据时难以精准地理解和把握用户需求，尤其是在处理投诉问
题上面临极大挑战[2]。 
根据国家能源局监管热线收到的有效信息数据显示，2022 年投诉举报反映的
问题主要集中在电力行业，其次是新能源和可再生能源行业。电力行业投诉举报数
量为11968 件，占全部投诉举报数量的95.78%。电力用户对电费等问题的不满和
投诉率较高，直接影响到电力企业的用户满意度和声誉[3]。 
为了更好地解决这一问题，本课题设计了 Stacking 集成学习电力用户画像系
统，旨在通过构建模型并对电费敏感用户进行识别。电力用户画像系统具有以下重
要意义。 
（1） 提高用户满意度。电力企业能够通过Stacking集成学习电力用户画像系
统更好地了解用户的需求和偏好，从而提供更加个性化、精准的服务。电价变更、
电力检修等情况下，进行提醒服务，避免不必要的投诉，从而提高用户满意度[4]。 
（2） 提升电力企业竞争力。借助Stacking集成学习电力用户画像系统，电力
企业可以更好地利用用户数据，洞察市场需求，精准推出符合用户期望的产品和服
务，提升企业竞争力。 
（3） 推动电力行业的发展。电力用户画像系统有助于推动电力行业的数字化
转型和智能化升级。该系统不仅能够准确识别电费敏感用户，还能帮助电力企业分
析用户的用电行为和习惯。分析结果为可再生能源的合理配置和应用提供了重要
参考，推动清洁能源的普及和使用。因此，该系统为未来电力行业的可持续发展奠
定了基础[5]。 
综上所述，基于 Stacking 集成学习的电力用户画像系统在解决电力行业信息
过载问题、提高用户满意度、减少投诉数量以及推动电力行业的发展等方面具有重
要的研究背景和深远的意义。电力企业能够更好地适应市场需求，提供更加智能、
个性化的服务，实现电力行业的可持续发展，同时也符合国家推动数字化、智能化
发展的战略目标。

1.2.1 用户画像研究现状 
目前，用户画像通常有User Profile、User Persona与User Portrait 三种表达方
法。User Profile 侧重于用户信息标签化，反映用户角色属性；User Persona侧重用
户需求，对相同需求用户进行画像；User Portrait侧重用户历史行为，形成用户的
行为画像。用户画像技术有助于企业找到潜在的用户和已有用户的精细化需求，帮
助企业向用户提供针对性服务[6]。用户画像研究是一门涵盖多学科领域的重要研究
方向，旨在通过分析用户的行为、兴趣、特征等信息，构建用户的画像，从而更好
地了解用户需求，优化产品和服务[7]。用户画像技术已被广泛应用于多个领域。 
在社交媒体领域，杨阳等[8]通过分析弹幕内容和用户行为特征，构建用户画像，
提供更准确的用户推荐。Li等[9]利用微信小程序建立群体用户画像，帮助社交媒体
平台了解用户兴趣和互动方式。Li[10]在快手APP中应用用户画像理论，优化了短
视频平台，提高了用户体验。 
在商业与医疗领域，Liu 等[11]使用参考正演模型(Reference Forward Model，
RFM)构建了不同价值层级的用户画像。Xu等[12]提出了在线购物用户画像模型，帮
助电商更好地了解用户。王若佳等[13]通过构建用户画像和应用机器学习算法预测
用户流失。滕春娥等[14]针对在线医疗社区构建用户画像，了解用户健康需求。Gao
等[15]利用用户画像技术帮助医疗机构更好地理解患者需求和行为。Jiang等[16]采用
多模态神经网络研究了社区心理标签与用户画像模型间的关联。黄承宁等[17]提出
了基于用户画像的抑郁倾向人群识别方法。Min 等[18]以以太坊数据进行了用户画
像构建。Wang等[19]通过用户画像技术助力大数据工程。王杰等[20]基于知识图谱和
用户画像，搭建了金融产品推荐系统。凌坤等[21]基于用户画像算法，优化了协同过
滤推荐算法。Li等[22]考虑市场响应潜力，构建了电动汽车用户画像。 
在教育与安全领域，余明华等[23]通过可视化学习分析方法，构建了研究性学
习学生的画像。Zhang 等[24]搭建了基于用户画像的农业科技资源的上下文推荐系
统。Ni等[25]研究了基于大数据分析的用户画像在工业设计教育中的应用。Chen等

模糊多标签学习算法用于信用用户画像，有助于金融机构更好地评估信用风险。Xu
等[28]提出了一种基于用户画像的网络犯罪快速检测方法。商瀑等[29]提出了基于用
户画像技术的大数据侦查框架，为执法和安全领域提供了数据分析的支持。

1.2.2 神经网络在用户画像领域的研究现状 
神经网络在用户画像领域的广泛应用得益于深度学习技术的发展。深度学习
赋予神经网络强大的模式识别能力，使其能够准确挖掘大规模、复杂数据中的用户
行为和兴趣模式。下面从特征处理、预测模型和集成学习三方面进行分析。 
在特征处理优化方面，汪颖等[41]提出了一种适用于海量用户用电行为聚类及
分析的算法，提取用户用电行为特征，构建多层去噪自编码网络，实现多维特征的
降维。Wang等[42]将历史样本映射到多维样本空间，分析不同维度的数据分布情况，

2.2 特征构造方法 
特征构造涉及从原始数据中提取相关信息以供模型学习。中文语言的复杂性
和表达方式的多样性导致在处理中文任务中，特征构造尤为关键。Word2Vec、
Doc2Vec和TF-IDF为三种常见的特征构造方法，以下是对这三种方法的简要介绍。 
（1）Word2Vec 
Word2Vec[62]通过将词语嵌入到高维空间中，捕捉单词之间的语义关系。
Word2Vec 通过将单词映射到实数向量，使得相似含义的单词在向量空间中的距离
更近。该方法有两个主要的模型Skip-Gram和CBOW。Skip-Gram模型通过给定中
心词来预测其周围的上下文词，而CBOW通过给定周围的上下文词来预测中心词。 
（2）Doc2Vec 
Doc2Vec[63]将整个文档表示为固定长度的向量。通过捕捉文档中的语义信息，
将文档嵌入到连续的向量空间中，为后续的文本分析任务提供了更为丰富的特征
表示。使用Doc2Vec 进行特征构造时，首先构建语料库，将文档转化为对应的向
量表示。训练过程中Doc2Vec会为每个文档和单词学习一个向量，相似的文档在
向量空间中更接近。语义信息的保留使得Doc2Vec在处理文本分类等任务时表现
出色。Doc2Vec考虑了单词的顺序和上下文关系，更好地捕捉了文档的语义信息，
其在处理长文本或需要上下文信息的任务中更为有效。 
（3）TF-IDF 
TF-IDF[64]通过考虑词频和逆文档频率，凸显文本中重要且具有区分性的词汇，
从而为文本数据建立更具信息量的特征表示。TF衡量了在给定文档中某个词出现
的频率。对于文档中的每个词，TF值等于该词在文档中出现的次数除以文档中总
词数，高TF值表示词在文档中的重要性。IDF考虑了词的全局重要性。文档总数
除以包含某个词的文档数，再取对数得到IDF。IDF的作用是降低在文本集合中高
频词的权重，提高低频词的权重，以更好地区分文档。

2.3 集成学习技术 
集成学习通过结合多个弱学习器创建一个强大模型来提高画像的准确性和泛

种技术的简要介绍。 
（1）Bagging 
Bagging[65]的核心思想是通过构建多个独立的学习器，使用不同的训练数据集
或特征集进行训练，最终通过投票或平均的方式获得更为稳定和准确的预测结果。 
在训练每个基学习器时，通过有放回地随机抽样训练数据，构建多个与原始数
据集规模相同但具有差异性的子集，减少过拟合的风险。合并预测结果，降低方差
提高整体模型鲁棒性。在预测阶段，Bagging采用硬投票或软投票来整合每个基学
习器的输出。对于分类问题，硬投票通过多数表决确定最终类别；对于回归问题，
软投票通过对每个学习器的预测结果进行平均得到最终输出。Bagging训练流程如

（3）Stacking 
Stacking[67]通过组合多个基本学习模型的预测结果，利用元模型对结果进行进

通过使用多个不同的基本模型，Stacking能够捕捉数据中的不同特征，提高模
型准确率。Stacking引入次级模型对基本模型的输出进行整合，提高模型的泛化能
力。次级模型可以结合各个基本模型的输出，更好地适应不同的数据分布。 
Stacking 对于处理复杂关系和噪声数据有较强的鲁棒性。通过整合多个模型的
特性，Stacking 能够减小单模型的过拟合或欠拟合问题，使得整体模型更为健壮。

优点。第一阶段利用MLP、CNN-LSTM和XGB对用户敏感度进行预测，第二阶
段采用RF识别出电费敏感用户。 
2.4 本章小结 
本章总结了用户画像构建的五种方法，包括基于本体、兴趣偏好、主题或话题
以及行为日志。在特征构造方面，Word2Vec、Doc2Vec和TF-IDF为用户画像提供
了多样性的特征表示，有助于全面地理解用户兴趣和行为。通过集成学习技术整合
多个学习器的优势，可以提高画像结果的准确性和泛化性。

3.3 多层源特征构造层 
为了更深层次的挖掘用户特征，将文本类与数值类信息进行单独挖掘。利用多

3.3.1 多层特征构造 
针对文本类信息，传统的特征构造方法角度单一，多层特征构造方法从上下文
依赖、用户之间关系和全局信息三个层面考虑，构造词语、用户、全局三层特征。
词语层面特征侧重于单个用户内部特征，用户层面特征侧重于不同用户之间特征，
全局层面特征侧重于词语在某类用户中的重要性。三个层面互相补充，充分构造文
本类特征。

1.24%，在活跃用户上提升1.45%、0.45%，证明了模型的效果。多层源特征构造方
法可以全面的构造用户特征，Stacking集成学习两阶段预测可以充分的学习用户复
杂的特征。

4.1 可行性分析 
（1）理论可行性 
电力用户画像系统基于现有的数据分析、用户画像构建和集成学习等理论基
础，有充分的理论支持。用户画像构建方法和数据分析技术在实际应用中已经被证
明可以为企业提供重要的业务洞察。通过对用户进行画像，筛选电费敏感用户，分
析用户的用电行为、欠费情况以及违约情况，可以得出对用户群体的深入认识，从
而优化服务策略，提高用户满意度和维护用户关系。综上，电力用户画像系统在理
论上是可行的。 
（2）技术可行性 
前端采用layui 和 jquery 框架，后端采用 Django 搭建可视化数据平台，均为
成熟、稳定的技术框架，能够快速开发和部署系统。数据存储采用MySQL数据库，
MySQL是一种广泛应用的关系型数据库管理系统，能够满足数据存储的需求。数
据分析和用户画像模型构建使用Pandas和TensorFlow等工具，强大的数据处理和
机器学习框架，能够高效地处理大量数据和构建复杂的模型。另外，Echarts 和
WordCloud 等图形展示工具也能够实现结果可视化，使数据更加直观、易于理解。

第6章 结论与展望 
在智能电网不断发展的背景下，电力行业积累了海量数据，导致信息过载的问
题愈发突出。用户画像技术崭露头角，成为解决电力行业信息过载难题的有力工具。
用户画像技术以其真实性、精准性以及时效性等特点，为电力行业带来了前所未有
的机遇。本课题在此背景下，提出了多层源特征Stacking集成学习用户画像模型，
对电费敏感用户进行识别。助力电力企业实现更精准的电费敏感用户定位，提供针
对性服务，提升用户满意度降低投诉率，达到优化运营的目标。主要研究成果如下： 
（1）针对现有特征处理方法的局限性，提出了一种多层源特征构造方法。该
方法针对文本类信息与数值类信息进行独立处理，充分挖掘了信息的多层、多源特
征。通过多层特征构造，系统从词语、用户和全局三个层面深度挖掘文本类信息；
通过多源特征构造，系统从工单、通话和电费三个源头获得用户数值类信息，以此
构建用户特征，为模型提供更为丰富的输入。 
（2）为了解决现有用户画像模型对于全局特征、局部特征、时序特征及缺失
值的问题，提出了 Stacking 集成学习两阶段预测模型。首先，利用 MLP、CNN
LSTM和XGB在全局、局部、时序特征和缺失值方面的优点在第一阶段对用户敏
感度进行预测。其次，通过RF算法在第二阶段对电费敏感用户进行识别。本课题
所提模型在F1值和精确率两方面，较其它用户画像模型均有所提升，准确的对用
户进行画像，帮助电力企业更有针对性地开展服务与管理。 
（3）构建了电力用户画像系统，包括用户管理、数据管理、数据预处理、数
据分析和用户画像构建五个模块。通过该系统对电费敏感用户进行了画像构建，并
提供了针对性服务。同时，系统提供了模型测试、模型校正以及用户画像结果的修
正功能，确保系统的准确性和可靠性。此外，系统分析了电力用户的欠费行为和违
约金缴纳等情况。通过计算综合相关系数等方式，挖掘了潜在的信息，有助于更好
地了解用户行为和支付习惯。本系统不仅为电力用户提供了个性化服务，还帮助电
力公司更好地了解用户行为和支付情况，从而更有效地管理电力资源和维护用户
关系。 
本课题提出的基于 Stacking 集成学习的电力用户画像系统在电力行业具有重
要的现实意义。通过多层源特征构造与两阶段预测模型，系统能够有效识别电费敏
感用户。本系统不仅为电力企业提供了优化服务与管理工具，同时也为电力行业信
息处理的信息过载问题提供了可行的解决方案。今后的研究工作将从以下两个方
面进行。
