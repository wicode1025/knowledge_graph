智能电网的发展,数据来源变得多样化且复杂。多源 电力系统数据融合是将来自不同源的数据进行集成 和整合的过程[4]。通过高效的数据融合技术,可以全 面捕捉电力系统的运行状态和潜在规律。 面对数据的多源性与异构性挑战,本文引入典 型相关分析(CCA)数据融合工具。典型相关分析能够 跨越不同数据领域的界限,捕捉并提取出各数据源 之间潜在的关联性特征,将它们映射到一个统一的 特征空间内[5]。在这个过程中,强相关的特征会被显 著增强,而弱相关或无关的特征则会被削弱或剔除, 从而实现了数据的深度整合与降维[6]。 设有 2 个数据集 X Î Rn  ́ p 和 X Î Rn  ́ q ,其中 n 是 样本数量,p 和 q 分别是 2 个数据集的特征维度。典  型相关分析的目标是找到 2 组线性变换 a Î Rp 和 b Î Rq ,使得变换后的电力系统数据 aT 在数据融合的基础上,知识抽取成为提取有价 值信息和构建知识库的关键环节。知识抽取涉及从 海量数据中自动识别并提取出与电力系统相关的实 体、关系、事件等关键信息[10]。通过知识抽取将原始数 据转化为结构化的知识表示,为后续构建知识图谱 提供素材。 面对如文本报告和视频监控资料,采用词嵌入 技术,即构建定制化的词向量模型。词嵌入技术通常 通过图神经网络模型将词汇映射到高维向量空间, 使得在数值层面上能够反映文本内容的相似性和差 异性[11]。这样的处理方式,使得计算机能够直接操作 并理解文本数据。 在图卷积的框架下,空间基方法通过定义一个 操作,该操作围绕每个中心节点(即图中的每个像素 点),聚合其直接邻居节点(即相邻像素)的信息。这一 过程通常涉及一个“卷积核”,用于计算中心节点与 其邻居节点特征的加权和,这一过程不仅捕获了节 点(像素)的局部空间依赖性,还通过节点的更新表 示反映了这种依赖性的变化[12]。 具体到实体抽取阶段,对实体特征进行文本相 似度加权分析,精准衡量实体间的相似程度。这一过 程依赖于精确的计算公式,确保相似度评估的科学 与准确性。假设有两个实体 e1 和 e2 ,它们的特征向量 分别为 f1Î Rd 和 f2 Î Rd(这里 d 是特征维度):  sin(e1e2) = cos( f1f2) = f1 × f2   f1 f2
