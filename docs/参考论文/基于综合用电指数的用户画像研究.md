基于综合用电指数的用户画像研究  蔡艳婧 陆 健 曹春梅 徐 立  (江苏商贸职业学院电子与信息学院,江苏 南通 226001)  摘 要:电力系统所用的用户画像不能对用户行为进行精准识别,导致无法满足电力企业的需求。 本研究提出基于综合用电指数的用户画像,利用综合用电指数构建指标体系,再根据用户信息建 立行为标签库,根据指标评分来计算综合用电指数,最后用 Canopy 改进 K-means 算法生成用户画 像。通过案例分析可以看出,该方法能够精确地分析出用户的用电习惯,并对用户提出指导性意 见,避免资源的浪费。 关键词:电力;用电指数;用户画像;综合  中图分类号:TP181 文献标志码:A 文章编号:1003-5168(2022)12-0021-04  DOI:10.19968/j.cnki.hnkj.1003-5168.2022.12.004  Research on User Portrait Based on Comprehensive Power  Consumption Index  CAI Yanjing LU Jian CAO Chunmei XU Li  (School of Electronics and Information,Jiangsu Vocational College of Commerce and Trade,Nantong 226001,  China)  Abstract: The user portrait used in power system can not accurately identify the user behavior and can  not meet the needs of power enterprises.The research on user portrait based on comprehensive power consumption index is proposed.The index system is constructed by using the comprehensive power consumption index,and then the behavior label library is established according to the user information.The comprehensive power consumption index is calculated according to the index score.Finally,the user portrait  is generated by using Canopy improved K-means algorithm.Through case analysis,it can be seen that the  design method can accurately analyze the habits of users,put forward guiding opinions for users,avoid resource waste.  3 再 次 从 列 表 List = [ x1 ,x2 ,x3 ,...,xn ] 剩 余 的 样 本点中随机选取一个数据,记为 Q,设其到 O 的距 离 为 D。 根 据 强 弱 规 则 处 理 Q 点 :若 D>T 1,则 Q 生成新 Canopy 子集,并将 Q 从列表 List 中删除;若 D≤T 1,则将 Q 弱标记,且 Q 放入 So 子集;若 D≤T 2,则 将 Q 强标记,且 Q 放入 So子集。 不断对数据进行迭代,循环执行第三步,直到 输出的数据 List 中元素数目清零,完成 Canopy 聚类 运算。  2 案例分析  为了检验本研究设计的指标体系的应用效果, 选取管区内 A、B、C、D 4 家典型企业用户作为试验 对象。监测时间为 2020 年 10 月到 2021 年 9 月,分 析其用电情况。通过对用电情况进行调研和考察, 同时参考企业的基本信息和信用体系评分等信息, 依据综合用电指数指标体系的评价方法,绘制客户 的外部特征。综合用电指数结果如表 2 所示。 在不同的二级指标考核下,4 家企业的得分综 合体现为一个外在的表现特征,对这 4 家企业进行 用电画像的绘制,结果如图 2 所示。 通 过 对 用 户 用 电 画 像 进 行 分 析 ,可 以 看 出 ,A 企业的用电行为习惯良好,企业在用电时能够遵循 经济用电的原则,避免能源的浪费,与另外 3 家企 业相比,其有着十分明显的优势,对该企业的建议 是继续保持企业的用电习惯,合理分类用电,关注  图 1 定量指标隶属度函数  极大型 极小型 居中型 区间型  S SS S  d  d dd  0 00 0  100  100  100  100  60 60 60 60  基于综合用电指数的用户画像研究
