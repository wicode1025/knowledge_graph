# 电力用户画像系统 V2.0 完整设计方案

## 一、系统概述

### 1.1 定位
面向家庭用户的电力用电全流程模拟系统，以"月"为周期进行用电管理、计费、缴费和设备维护。

### 1.2 双子系统架构

| 子系统 | 用户 | 核心功能 |
|--------|------|----------|
| 用户端 | 普通用户 | 个人信息编辑、用电画像、设备管理、缴费、报修 |
| 管理端 | 管理员 | 数据管理、用户管理、"推进至下月"一键执行、维修审核 |

### 1.3 月度模拟机制

管理员点击 **"推进至下月"** 按钮后，系统自动执行：
1. 根据每位用户的设备清单计算上月用电量
2. 生成上月电费账单并推送
3. 检测连续2月未缴费用户，在账单上标注警告
4. 更新所有设备的使用年限和损坏概率
5. 将当前月份 +1

## 四、核心算法模型

### 4.1 老化功耗计算模型

设备有效功率随使用年限增长：

```
P_effective = P_rated × (1 + aging_rate × min(1, (usage_years / lifespan)²))

其中：
  P_rated = 额定功率
  aging_rate = 该类型电器老化功耗增幅（来自device_type_config）
  usage_years = 已使用年限
  lifespan = 预期使用寿命
```

**示例**：一台使用了8年的壁挂式空调（额定1200W，寿命10年，aging_rate=0.25）
```
P_effective = 1200 × (1 + 0.25 × (8/10)²)
            = 1200 × (1 + 0.25 × 0.64)
            = 1200 × 1.16
            = 1392W
```
→ 相比新机，功耗增加约16%

### 4.2 损坏概率模型（威布尔分布）

```
P_damage(t) = 1 - exp(-(t/η)^β)

其中：
  t = 已使用年限
  η = 特征寿命（= lifespan × 1.2，因为特征寿命为63.2%失效点）
  β = 威布尔形状参数（来自device_type_config，β>1表示耗损失效）
```

**示例**：洗衣机使用了6年（寿命8年，β=3.0）
```
η = 8 × 1.2 = 9.6
P_damage(6) = 1 - exp(-(6/9.6)^3.0)
            = 1 - exp(-0.244)
            = 1 - 0.783
            = 0.217
```
→ 约21.7%的损坏概率

### 4.3 月用电量计算公式

```
E_month = P_effective × daily_hours × days_in_month × seasonal_factor / 1000

其中：
  daily_hours = 日均使用时长
  seasonal_factor = 季节系数（来源于使用习惯的季节系数）
  P_effective = 考虑老化后的有效功率
```

**示例**：冰箱（有效功率180W，全天运行，10月）
```
E_month = 180 × 24 × 31 × 1.0 / 1000 = 133.92 kWh
```
