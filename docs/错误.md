Diagnosis
- Error type: runtime/build error from vite's Vue plugin: "crypto.hash is not a function" ([line 69](#L69)). The plugin points at frontend/src/App.vue ([line 70](#L70) — file in repo: https://github.com/wicode1025/knowledge_graph/blob/master/frontend/src/App.vue).
- Root cause: Netlify is using Node.js 18.20.8 while this Vite version requires Node >= 20.19 or >= 22.12 (reported at [line 62](#L62)). The older Node runtime causes mismatches in the crypto / Web Crypto APIs used by Vite/plugin-vue, producing the "crypto.hash is not a function" error during build.

Solution (recommended: upgrade Node on Netlify)
1. Configure Node >= 20.19 (or >= 22.12) for Netlify. You can do one of the following (pick one and push/deploy):

   - Add a .nvmrc file at the repo root (or the frontend subfolder if you build from there) containing a supported version, for example:
   ```text
   20.19.0
   ```
   Commit and push.

   - Or add an engines field to package.json (frontend/package.json if you build from frontend/):
   ```json
   {
     "engines": {
       "node": ">=20.19.0"
     }
   }
   ```
   Commit and push.

   - Or set the NODE_VERSION environment variable in the Netlify site settings to a supported version (e.g. "20.19.0" or "22.12.0").

2. After changing the Node version, clear the build cache and redeploy the site from the Netlify UI (or trigger a new deploy). This ensures the new Node runtime is used.

Netlify docs for changing Node versions (required): https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript

Alternative (less recommended)
- If you cannot upgrade Node on Netlify for some reason, you could instead downgrade Vite/plugin-vue to a version that supports Node 18 — but this is a workaround and may introduce other incompatibilities. Prefer upgrading Node.

Notes
- The error originates in frontend/src/App.vue as shown by the plugin stack trace; upgrading Node to a supported version should resolve the crypto API mismatch and allow Vite to build normally.
