## 二、查询类型详细设计

### 2.1 类型查询（Categorical Query）

**适用字段**：user_type, province, city, house_type, enterprise_type, cluster_label, payment_status, user_category, power_category

**查询控件设计**：
```
┌─────────────────────────────────────────────────────────┐
│  类型查询                                                │
├─────────────────────────────────────────────────────────┤
│  查询字段: [下拉选择字段 ▼]                              │
│                                                         │
│  匹配方式: ○ 精确匹配  ○ 模糊搜索                        │
│                                                         │
│  输入值: [文本输入框          ] 或 [下拉选择 ▼]         │
│                                                         │
│  [添加条件] [清除条件]                                   │
└─────────────────────────────────────────────────────────┘
```

**查询逻辑**：
```python
# 精确匹配
SELECT * FROM users WHERE field = value

# 模糊搜索
SELECT * FROM users WHERE field LIKE '%value%'
```

### 2.2 数值查询（Numeric Query）

**适用字段**：avg_daily_kwh, total_kwh, max_daily_kwh, min_daily_kwh, std_daily_kwh, variance_kwh, total_days, device_count, device_kwh_total, total_fee, avg_fee, membership_0/1/2/3

**查询控件设计**：
```
┌─────────────────────────────────────────────────────────┐
│  数值查询                                                │
├─────────────────────────────────────────────────────────┤
│  查询字段: [下拉选择字段 ▼]                              │
│                                                         │
│  范围选择:  [等于] [大于] [小于] [区间] [Top N]         │
│                                                         │
│  当选择"等于":  输入值: [_________]                      │
│  当选择"大于":  输入值: [_________]                      │
│  当选择"小于":  输入值: [_________]                      │
│  当选择"区间":  最小值: [_________] 最大值: [_________] │
│  当选择"Top N": 前 [___] 名 (N=10/20/50/100)            │
│                                                         │
│  [添加条件] [清除条件]                                   │
└─────────────────────────────────────────────────────────┘
```

**查询逻辑**：
```python
# 精确等于
WHERE field = value

# 大于/小于
WHERE field > value
WHERE field < value

# 区间
WHERE field BETWEEN min AND max

# Top N
WHERE field IN (SELECT TOP N field ORDER BY field DESC)
```

### 2.3 标签查询（Tag Query）

**适用字段**：energy_level, behavior_label, consumption_pattern, seasonal_adaptation

**查询控件设计**：
```
┌─────────────────────────────────────────────────────────┐
│  标签查询                                                │
├─────────────────────────────────────────────────────────┤
│  查询字段: [下拉选择 ▼]                                  │
│                                                         │
│  可选标签:                                               │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐  │
│  │  极高  │ │   高   │ │   中   │ │   低   │ │  极低  │  │
│  │   ○    │ │   ○    │ │   ●    │ │   ○    │ │   ○    │  │
│  └────────┘ └────────┘ └────────┘ └────────┘ └────────┘  │
│                                                         │
│  选择模式: ○ 单选  ○ 多选(任意)  ○ 多选(全部)           │
│                                                         │
│  [添加条件] [清除条件]                                   │
└─────────────────────────────────────────────────────────┘
```

**查询逻辑**：
```python
# 单选
WHERE field = 'value'

# 多选(任意满足)
WHERE field IN ('value1', 'value2', 'value3')

# 多选(全部满足 - 需要多次查询后取交集)
WHERE field = 'value1' INTERSECT WHERE field = 'value2'
```

## 三、查询结果分析设计

### 3.1 分析维度确定规则

根据查询所使用的字段类型，确定展示的分析维度：

```
查询字段类型 ──> 分析维度 ──> 图表类型

类型字段 ──> 该字段的分布统计 ──> 饼图/柱状图
           ├─> 与其他分类字段的交叉分析 ──> 堆叠图
           └─> 查询结果的基本统计 ──> 摘要卡片

数值字段 ──> 查询结果的数值分布 ──> 直方图/箱线图
           ├─> 该数值的历史趋势(如果有时序数据) ──> 折线图
           ├─> 与能耗等级的关联分析 ──> 散点图/热力图
           └─> 与总体均值对比 ──> 对比柱状图

标签字段 ──> 标签分布统计 ──> 饼图/环形图
           ├─> 与其他标签的关联矩阵 ──> 热力图
           ├─> 标签下的数值分布 ──> 箱线图
           └─> 聚类分布 ──> 饼图
```

## 四、图表类型详细设计

### 4.1 饼图 (Pie Chart)
**适用场景**：分类字段的分布统计
**数据结构**：`{ label: string, value: number }`
**示例**：用户类型分布、省份分布、能耗等级分布

### 4.2 柱状图 (Bar Chart)
**适用场景**：分类字段的对比、排行
**数据结构**：`{ category: string[], series: { name: string, data: number[] } }`
**示例**：城市用电排行、设备用电排行

### 4.3 直方图 (Histogram)
**适用场景**：数值字段的分布区间
**数据结构**：将数值划分为区间，统计每个区间的频数
**示例**：日均用电分布、电费分布

### 4.4 箱线图 (Box Plot)
**适用场景**：数值字段的统计特征（最小值、Q1、中位数、Q3、最大值）
**数据结构**：`{ min, Q1, median, Q3, max }`
**示例**：不同能耗等级的用电量对比

### 4.5 折线图 (Line Chart)
**适用场景**：数值随时间的变化趋势
**数据结构**：`{ date: string[], value: number[] }`
**示例**：月度用电趋势、电费趋势

### 4.6 堆叠图 (Stacked Chart)
**适用场景**：多维度的分类对比
**数据结构**：多个分类字段的交叉统计
**示例**：能耗等级+行为标签交叉分析

### 4.7 热力图 (Heatmap)
**适用场景**：标签之间的关联强度
**数据结构**：矩阵形式 `matrix[row][col] = value`
**示例**：标签关联矩阵、相关矩阵

### 4.8 雷达图 (Radar Chart)
**适用场景**：多维度的综合评价
**数据结构**：`{ indicator: { name, max }, value: number[] }`
**示例**：用户综合画像、设备用电画像

## 五、数据处理流程

### 5.1 查询处理流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  用户输入   │───>│  字段解析   │───>│  SQL生成    │───>│  数据查询   │
│  查询条件   │    │  类型判断   │    │  条件组合   │    │  结果返回   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                                   │
                                                                   ▼
                    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
                    │  图表配置   │<───│  分析维度   │<───│  结果分析   │
                    │  生成图表   │    │  确定       │    │  数据加工   │
                    └─────────────┘    └─────────────┘    └─────────────┘
```

### 5.2 后端数据处理

```python
# 查询结果处理
def process_query_result(users, query_fields):
    result = {
        'total': len(users),
        'data': users,  # 分页数据
        'summary': {},  # 统计摘要
        'analysis': {}   # 分析图表数据
    }

    # 1. 计算统计摘要
    result['summary'] = calculate_summary(users)

    # 2. 根据查询字段确定分析维度
    analysis_dimensions = determine_analysis_dimensions(query_fields)

    # 3. 生成各维度的分析数据
    for dimension in analysis_dimensions:
        result['analysis'][dimension] = calculate_dimension_data(
            users, dimension
        )

    return result


# 分析维度确定
def determine_analysis_dimensions(query_fields):
    dimensions = set()

    for field in query_fields:
        if field in CATEGORICAL_FIELDS:
            dimensions.add('distribution')  # 分布分析

        if field in NUMERIC_FIELDS:
            dimensions.add('numeric_dist')  # 数值分布
            dimensions.add('comparison')   # 与总体对比

        if field in TAG_FIELDS:
            dimensions.add('tag_dist')      # 标签分布
            dimensions.add('tag_relation')  # 标签关联

    return list(dimensions)
```

## 六、API接口设计

### 6.1 查询分析接口

**请求**：
```
GET /api/kg/query/analysis/
POST /api/kg/query/analysis/

{
    "conditions": [
        {"field": "province", "operator": "=", "value": "广东"},
        {"field": "avg_daily_kwh", "operator": ">", "value": 100},
        {"field": "energy_level", "operator": "IN", "value": ["极高", "高"]}
    ],
    "logic": "AND",  // AND or OR
    "page": 1,
    "page_size": 20,
    "include_analysis": true  // 是否包含分析数据
}
```

**响应**：

### 7.1 组件结构

```
QueryPage
├── QueryTypeSelector (查询类型切换)
│   ├── TypeQuery (类型查询组件)
│   ├── NumericQuery (数值查询组件)
│   └── TagQuery (标签查询组件)
├── ConditionBuilder (条件构建器)
│   ├── ConditionItem (单个条件)
│   └── LogicSelector (AND/OR选择)
├── ActionButtons (操作按钮)
│   ├── ExecuteButton
│   ├── ClearButton
│   └── SaveQueryButton
├── ResultSummary (结果摘要卡片)
├── AnalysisCharts (分析图表区域)
│   ├── PieChartComponent
│   ├── BarChartComponent
│   ├── HistogramComponent
│   ├── BoxPlotComponent
│   ├── LineChartComponent
│   └── HeatmapComponent
└── ResultTable (结果数据表格)
    ├── TableHeader
    └── TableBody (分页数据)
```
