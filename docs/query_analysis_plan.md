# 查询分析页面设计方案

## 一、查询类型分类

### 1. 类型查询（分类字段）
- **适用字段**：用户类型、省份、城市、房屋类型、企业类型
- **查询逻辑**：精确匹配/模糊搜索
- **查询方式**：下拉选择 + 搜索

### 2. 数值查询（数值字段）
- **适用字段**：日均用电量、总用电量、最大日用电、最小日用电
- **查询逻辑**：范围查询（大于、小于、区间）
- **查询方式**：数值输入 + 范围选择（大于/小于/区间）

### 3. 标签查询（分类标签）
- **适用字段**：能耗等级、行为标签、用电模式
- **查询逻辑**：多选匹配
- **查询方式**：标签按钮组（可多选）

### 4. 组合查询
- 支持多种条件组合（AND/OR）
- 支持添加多个条件

---

## 二、查询后分析图表设计

根据查询结果的不同，动态生成不同类型的分析图表：

### A. 用户属性分析（查询类型字段后）
- 用户类型分布 → 饼图/柱状图
- 省份/城市分布 → 横向柱状图
- 能耗等级分布 → 堆叠柱状图

### B. 能耗分析（查询数值字段后）
- 查询用户的日均用电分布 → 直方图
- 能耗等级分布 → 饼图
- 与总体平均对比 → 折线图/柱状图

### C. 行为分析（查询标签字段后）
- 行为标签分布 → 饼图
- 能耗 vs 行为交叉分析 → 堆叠图
- 用电模式分布 → 柱状图

### D. 综合分析（组合查询后）
- 多种维度综合展示
- 导出统计报告
