# 管理员知识图谱设计稿 V1.0

## 一、设计目标

管理员知识图谱需要实现全局纵览，能够：
1. 一眼看清所有用户及其设备关系
2. 通过颜色/大小/形状区分用户类型和能耗等级
3. 支持按能耗等级、设备类型筛选
4. 右侧侧边栏展示聚合统计数据
5. 点击节点查看该用户/设备的详细信息

---

```
全员用户 ────────────┼─ 空调(1.5匹)
                        │  ├─ ...
                        │
                        ├─ 王强(H0008) [摆渡型/7台/月均300kWh]
                        │  ├─ ...
                        │
                        ├─ 赵敏(H0009) [普通型/7台/月均220kWh]
                        │

```

### 层级说明

| 层级 | 节点类型 | 说明 |
|------|----------|------|
| L0 | 用户节点 | 每个用户一个节点，颜色表示能耗等级，大小表示用电量 |
| L1 | 设备节点 | 每个用户下挂设备，颜色表示设备类别 |

---

## 三、节点视觉设计

### 3.1 用户节点

| 属性 | 值 |
|------|-----|
| 形状 | 圆形 |
| 大小 | 40-70px（按月均kWh缩放） |
| 颜色 | 按能耗等级：节能型`#67c23a` / 普通型`#5470c6` / 摆渡型`#e6a23c` / 高耗能型`#e74c3c` |
| 边框 | 3px `#fff` |
| 标签 | 显示姓名 + 能耗等级，字号12px |

### 3.2 设备节点

按6种类别着色（与用户端一致）：

| 类别 | 色值 |
|------|------|
| 空气调节 | `#a8d8ea` |
| 厨房电器 | `#fce4b8` |
| 清洁卫生 | `#f8cecc` |
| 影音娱乐 | `#d5c4e1` |
| 办公数码 | `#b5d8c3` |
| 照明 | `#f9f3c1` |

大小：20px，损坏设备加红色虚线边框。

## 四、布局参数

```
repulsion: 250          // 适中排斥力，用户节点间保持距离
gravity: 0.1            // 适当向心力，不散太开
edgeLength: [80, 200]   // 用户到设备连线长度
```

## 六、筛选功能

### 6.1 筛选栏

位于图谱顶部：

```
[能耗等级 ▾] [设备类别 ▾] [缴费状态 ▾]
```

| 筛选项 | 选项 |
|--------|------|
| 能耗等级 | 全部 / 节能型 / 普通型 / 摆渡型 / 高耗能型 |
| 设备类别 | 全部 / 空气调节 / 厨房电器 / 清洁卫生 / 影音娱乐 / 办公数码 / 照明 |
| 缴费状态 | 全部 / 正常 / 欠费 |

### 6.2 筛选逻辑

- 选中筛选项后，不符合条件的用户节点和设备节点变淡（opacity 0.2）
- 选择"全部"恢复所有节点
- 支持组合筛选

## 七、交互设计

| 操作 | 目标 | 行为 |
|------|------|------|
| 单击 | 用户节点 | 右侧面板展示该用户详情 |
| 单击 | 设备节点 | 右侧面板展示设备详情 |
| 双击 | 用户节点 | 展开/折叠该用户的设备子节点 |
| 拖拽 | 节点 | 移动位置 |
| 滚轮 | 画布 | 缩放 |
| 单击空白 | 画布 | 取消选中，面板恢复统计视图 |
