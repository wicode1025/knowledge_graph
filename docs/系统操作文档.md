## 第1章 系统概述

### 1.1 系统简介

电力用户画像知识图谱系统（Knowledge Graph-based Power User Profiling System）是一套基于知识图谱技术的电力用户行为画像分析平台。系统采用前后端分离架构，以知识图谱技术为核心，对电力用户的用电行为、设备配置、缴费记录、家庭特征等多维度数据进行可视化建模与分析，帮助用户了解自身用电习惯，辅助管理者进行全局用电调度。

### 1.2 功能架构

系统按角色划分为两大功能模块：

**家庭用户模块**：面向普通用电用户，提供个人信息维护、用电设备管理、月度电费缴纳、设备故障报修、用电知识图谱可视化等功能，覆盖用户用电全生命周期。

**管理员模块**：面向系统管理员，提供月度仿真引擎调度、全局知识图谱监控、用户数据管理、维修工单审核、公告发布与留言管理等功能。

### 1.3 演示环境

| 系统管理员 | admin | 123456 | 管理后台全部权限 |
| 家庭用户 | user001 | 123456 | 示例用户，含完整数据 |
| 家庭用户 | user002 | 123456 | 示例用户，含完整数据 |
| 家庭用户 | user003 | 123456 | 示例用户，含完整数据 |

> **注意**：本系统为纯前端演示版本，数据存储于浏览器本地（localStorage）。清除浏览器缓存或更换浏览器将恢复初始演示数据。

### 1.4 技术特性

- **知识图谱可视化**：基于 ECharts 力导向图实现，支持节点点击详查、双击展开折叠、自由拖拽缩放
- **威布尔分布模型**：设备损坏概率采用 Weibull 分布计算，参数由设备类型、品牌品质系数（BQF）和已用年限共同决定
- **月度模拟引擎**：管理员一键触发，自动计算全量用户当月用电、生成账单、更新设备状态、检测欠费警告
- **老化功率修正**：设备有效功率随使用年限按二次衰减曲线动态调整，模拟真实设备老化趋势

## 第2章 家庭用户操作指南

### 2.1 登录系统

登录界面顶部默认为「家庭用户」模式。系统提供「管理员 Demo」和「用户 Demo」快速体验入口，点击即可自动填充对应演示账号。

**操作步骤**：

1. 打开系统网址，进入登录界面
2. 确认左上方角色切换按钮选中「家庭用户」（蓝色高亮状态）
3. 输入用户名和密码（或点击「用户 Demo」快速填充 user001 / 123456）
4. 点击「登 录」按钮
5. 验证通过后，系统自动跳转至用户首页

**注意事项**：
- 若用户名或密码输入错误，页面将显示红色错误提示文字，请根据提示修正后重新提交
- 连续输错不会锁定账户（演示环境）
- 新用户需点击「立即注册」进入六步注册向导创建账号

### 2.2 用户首页 —— 信息维护

登录后默认进入用户首页，页面采用左右双栏布局。左侧为主内容区，自上而下依次展示个人画像摘要、基本信息面板、住房信息面板、家庭成员面板、收入信息面板；右侧为系统公告栏和留言板。

#### 2.2.1 查看个人信息

页面顶部卡片展示用户姓名首字头像、姓名、性别、出生年份、学历和职业等关键身份标签。下方四个统计卡片分别显示上月总用电量、预估电费、用电设备数量和累计账单数。

基本信息面板以表格形式展示用户的姓名、性别、出生年月、民族、学历、婚姻状况、政治面貌、宗教信仰、职业、工作单位、联系电话、城乡分类、日常作息、健康自评和详细地址等 15 个字段。住房信息面板展示住房类型、建筑面积、户型结构、所在楼层、电梯配置、供暖方式、房屋朝向和房龄。收入信息面板展示个人年收入、家庭年收入、收入来源和经济自评。

#### 2.2.2 编辑个人信息

每个信息面板右上角均有「编辑」按钮。

**操作步骤**：
1. 点击面板右上角的「编辑」按钮，面板切换为可编辑状态
2. 各分类字段的下拉选项（如性别、学历、职业等）均从系统预设选项字典中获取
3. 修改完成后点击「保存」按钮
4. 系统通过 PUT 接口将修改数据实时更新至存储层
5. 页面数据即时刷新，无需手动刷新浏览器

#### 2.2.3 家庭成员管理

家庭成员面板顶部显示「管理」按钮。

**添加成员**：
1. 点击「管理」按钮，展开家庭成员的编辑界面
2. 填写新成员的姓名、选择与该用户的关系（本人/配偶/子女/父母等）
3. 选择是否同住，点击确认添加
4. 新成员立即出现在家庭成员列表中

**删除成员**：点击成员行右侧的删除按钮即可移除。

#### 2.2.4 留言板使用

右侧留言板用于与管理员进行消息沟通。

**发送留言**：
1. 在留言板区域点击「写留言」按钮
2. 在弹出的文本框中输入留言内容
3. 点击「发送」按钮提交

**撤回留言**：未回复的留言可点击「撤回」按钮删除。已收到管理员回复的留言无法撤回。

**查看回复**：管理员回复后，留言下方将显示管理员的回复内容。

### 2.3 用电画像 —— 知识图谱

用电画像是系统的核心可视化模块，将用户的用电数据以知识图谱形式直观呈现。

#### 2.3.1 界面布局

页面采用左右分栏布局：
- **左侧**：用户个人画像卡片（头像、身份标签、能耗等级、月均用电、设备数、缴费率等指标）、彩色标签词云（聚合用户信息维度标签）、基本信息简表、月度用电趋势折线图
- **右侧**：知识图谱力导向图（以用户节点为中心，向外辐射五大类节点）、图例（按颜色区分用户/大类/设备/账单状态等）

#### 2.3.2 图谱交互操作

**初始状态**：图谱仅显示中心用户节点（蓝色大圆）和五个大类节点（灰色方框），共 6 个可见节点和 5 条连接线。

**展开子节点**：双击任意大类节点（如「设备管理」），可展开该类别下所有子节点。再次双击则折叠收起。

**设备管理**：展开后显示用户全部用电设备，每台设备的节点大小与其功率成正比。节点颜色按设备类别区分：
- 蓝色：空气调节类（空调、风扇、电暖器等）
- 黄色：厨房电器类（冰箱、微波炉、电饭煲等）
- 绿色：清洁卫生类（洗衣机、热水器、吸尘器等）
- 红色：娱乐影音类（电视、电脑、音响等）
- 青色：照明设备类
- 棕色：其他设备类

**账单记录**：展开后显示近六个月缴费明细，绿色节点表示已缴，黄色节点表示未缴。

**用电特征**：展开后显示能耗等级标签、月均用电量和上月用电数据。

**家庭信息**：展开后显示家庭成员姓名及关系标签。

**画像标签**：展开后显示能耗类型、缴费信用、设备总数等综合评价标签。

**查看节点详情**：单击任意节点（设备、账单、标签等），右侧滑出详情面板，展示该节点的完整数据信息。

**图例参考**：图谱下方图例说明各颜色对应的含义，便于快速识别。

### 2.4 设备管理

设备管理页面以卡片网格形式展示用户所有用电设备，支持新增设备、删除设备以及按月查看设备用电数据。

#### 2.4.1 设备卡片信息

每张设备卡片包含以下信息：
- 设备名称（如「客厅空调」「双门冰箱」）
- 当月用电量（以环形进度图展示，弧线长度对应实际用电占最大可能用电的比例）
- 当前有效功率（已考虑设备老化的修正值，单位：瓦特 W）
- 使用习惯（全天运行/白天使用/夜间使用/偶尔使用/季节性使用）
- 已用年限（精确到一位小数）
- 损坏概率（百分比进度条，低于 50% 为蓝色正常，超过 80% 为红色危险）
- 运行状态标记（绿色「正常运行」或红色「已损坏」）

#### 2.4.2 添加新设备

添加设备通过四步向导完成，顶部有进度条指示当前步骤。

**第一步 —— 选择设备类别**：从六个大类（空气调节、厨房电器、清洁卫生、娱乐影音、照明设备、其他设备）中选择设备所属类别，每类下方显示该类包含的设备数量。

**第二步 —— 选择具体型号**：从该类别下的具体电器型号中选择，每个型号标注了额定功率范围和预期使用寿命。选定后进入参数填写。

**第三步 —— 填写设备参数**：填写以下信息：
- 品牌选择（格力/美的/海尔/西门子/松下/通用品牌/经济品牌，不同品牌对应不同的品牌品质系数 BQF）
- 已使用年限（单位：年，支持小数）
- 日均使用时长（单位：小时）
- 使用习惯（全天运行/白天使用/夜间使用/偶尔使用/季节性使用）
- 自定义设备名称（可选，不填则使用默认型号名称）

**第四步 —— 确认添加**：展示设备添加的汇总信息，包括设备名称、品牌、功率、使用习惯等。确认无误后点击「确认添加」提交。

系统将根据设备类型、已用年限和品牌品质系数，使用威布尔分布公式自动计算该设备的有效功率和损坏概率，并将数据写入存储层。

**防重复提交机制**：提交按钮在异步请求期间自动置灰禁用，按钮文字变为「提交中...」，请求完成后恢复可点击状态，防止重复写入。

#### 2.4.3 月份切换

页面顶部提供月份切换功能，显示当前查看的年份和月份。点击「<」和「>」按钮可切换到上一月或下一月，切换后所有设备卡片的环形用电图会更新为对应月份的数据。

#### 2.4.4 删除设备

点击设备卡片上的「删除」按钮，弹出确认对话框，确认后该设备被移除。设备删除将会级联清除该设备关联的用电记录数据。

### 2.5 电费缴费

电费缴费页面集成电费缴纳、维修费缴纳、缴费通知和缴费历史查询功能。

#### 2.5.1 电费缴纳

**查看待缴账单**：页面左上「电费缴费」模块展示当前用户所有待缴账单列表，每条显示账单月份、用电量和应缴金额，账单如有欠费警告会以红色标签标出。顶部状态徽章显示待缴账单总数和整体缴费状态。

**执行缴费**：
1. 在待缴账单列表中，点击目标账单右侧的「缴费」按钮
2. 弹出缴费向导（共四步）：
   - 第一步：展示账单摘要信息（月份、用电量、应缴金额），确认缴费对象
   - 第二步：选择支付方式（银行卡支付 / 微信支付）
   - 第三步：输入六位数字支付密码（模拟支付）
   - 第四步：系统模拟处理中（约 1.5 秒），完成后显示「缴费成功」
3. 缴费完成后，该账单状态从「未缴」变为「已缴」，缴费按钮消失，账单行标注实际缴费日期

#### 2.5.2 维修费用查阅

「维修缴费」模块展示本月待缴的维修费用明细（来源于管理员审核完成的维修工单）。每行显示维修项目描述、对应工单号后八位和费用金额。若本月无维修费用，显示「本月无维修费用」提示。

#### 2.5.3 缴费通知

右侧通知栏按月展示所有历史缴费通知清单。通知按时间倒序排列，正常通知以蓝色标识，欠费警告以红色标出。点击任意通知可展开查看该月账单详细信息。

#### 2.5.4 缴费历史查询

页面底部为缴费历史表格，列出用户所有月度账单记录，包含账单月份、用电量、电费金额、维修费金额、合计金额、缴费日期、缴费状态和操作列。

**筛选功能**：
- 按缴费状态筛选：通过下拉框选择「全部状态」「已缴费」「未缴费」
- 按年份筛选：通过年份下拉框选择特定年份，仅显示该年的账单

未缴账单在表格操作列提供「缴费」按钮，已缴费记录以灰色字体显示，不可再操作。

### 2.6 维修报单

维修报单页面用于设备故障报修和服务评价。

#### 2.6.1 设备状态概览

页面顶部展示用户设备的整体运行状态：
- **所有设备正常**：绿色提示条，显示「所有设备运行正常」及设备总数。正常设备以折叠列表收纳在页面下方，可点击展开查看详情
- **存在损坏设备**：红色卡片展示每台故障设备的信息（设备名称、类别、当前功率、使用年限、损坏概率），每张卡片右侧提供「报修」按钮

#### 2.6.2 提交报修

**操作步骤**（三步向导）：
1. **第一步 —— 选择故障设备**：从损坏设备列表中选择需要维修的目标设备
2. **第二步 —— 描述故障信息**：
   - 选择故障类型（共十种：无法开机、运行异常、漏电、噪音异常、不制冷/不制热、漏水、频繁启停、异味/冒烟、显示异常/报错、其他故障）
   - 填写故障描述文字（如具体现象、发生时间等）
   - 选择预约上门时间
3. **第三步 —— 确认提交**：汇总展示报修信息（设备名称、故障类型、故障描述、预约时间），确认无误后提交报修单

提交后数据写入工单表，管理员端即时可见该工单。

#### 2.6.3 报修记录追踪

页面底部以表格形式展示历次报修记录，包含单号、故障类型、当前状态、维修费用等字段。工单状态共有五种：
- **待处理**：工单已提交，等待管理员审核
- **已派单**：管理员已分配维修人员
- **维修中**：维修人员正在处理
- **已完成**：维修结束，费用已核算
- **已评价**：用户已完成服务评分

#### 2.6.4 服务评价

维修状态变为「已完成」后，用户可对本次维修服务进行评分（一至五星）。评分数据将记录在工单中，作为服务质量追踪的依据。

## 第3章 管理员操作指南

### 3.1 登录与身份识别

管理员登录流程与家庭用户一致。在登录界面将角色切换按钮选中「管理员」，点击「管理员 Demo」可快速填充管理员演示账号（admin / 123456）。登录成功后系统自动跳转至管理后台「系统概览」页面。

**管理员侧边导航栏**包含三个入口：系统概览、知识图谱、数据管理。左侧用户信息区显示管理员头像首字「管」、用户名「admin」和角色标识「管理员」。

### 3.2 系统概览

系统概览是管理员的核心操作台，提供月度调度、统计监控、公告管理和留言处理功能。

#### 3.2.1 月度推进引擎

月度推进是系统最重要的管理员操作，一步操作串联了全量用户的用电计算、计费、设备更新和风险检测。

**操作步骤**：
1. 在系统概览页面顶部，查看「当前系统月份」显示（如 2026-01）
2. 点击蓝色「推进至下月」按钮
3. 系统弹出确认对话框「确定推进至下月？」
4. 点击「确定」确认执行

**系统自动执行以下流程**：
1. 遍历所有非管理员用户的活动设备，逐台计算当月用电量（有效功率 × 日均使用小时数 × 当月天数），为每个用户生成 `ElectricityRecord` 月度用电记录
2. 汇总每位用户当月已完成的维修费用，与电费合计生成月度 `Bill` 账单
3. 检查每位用户是否存在连续两个月及以上未缴费记录，若存在则将最新账单标记为「欠费警告」
4. 更新每台设备的使用年限（+1/12 年），基于新的年限值重新计算损坏概率（Weibull 分布模型）
5. 损坏概率超过 80% 阈值的设备被标记为损坏状态（`is_active = 0`），并记录损坏日期
6. 系统月份自增一个月

推进完成后，页面上方显示绿色结果提示：「推进完成！XX 条记录，YY 张账单」。

#### 3.2.2 统计仪表盘

推进月份后，页面的六张统计卡片会展示当前系统运行状态：
- **用户总数**：系统中非管理员用户数量
- **活跃/总设备**：正常运行设备数占总设备数的比例
- **损坏设备**：已损坏设备总数
- **账单收缴**：已缴账单数占账单总数的比例

## 第4章 数据与算法说明

### 4.1 数据存储架构

本系统为纯前端演示版本，采用浏览器 localStorage 作为数据持久化方案。系统内置 10 份 JSON 种子数据文件（用户、设备类型、设备、用电记录、账单、维修工单、系统月份、选项字典、公告、留言），在用户首次访问时通过 `initStore()` 自动加载至 localStorage。

### 4.2 演示数据规模

| 数据类别 | 数量 | 说明 |
|---------|------|------|
| 演示用户 | 4 人 | 管理员 1 人 + 家庭用户 3 人（王建国/陈美丽/李大爷） |
| 预设电器 | 34 种 | 覆盖空气调节/厨房电器/清洁卫生/娱乐影音/照明设备/其他设备六大类 |
| 用电设备 | 20 台 | 3 个家庭用户共计 20 台设备 |
| 用电记录 | 90+ 条 | 覆盖 2025-08 至 2026-01 共 6 个月 |
| 月度账单 | 16+ 张 | 对应各月份的用电账单 |
| 选项字典 | 19 类 | 性别/民族/学历/婚姻/政治面貌/宗教/职业/住房类型/供暖方式/朝向/作息/健康/收入来源/财富等级/家庭成员关系/故障类型/使用习惯/使用频率/使用季节 |

### 4.3 威布尔分布模型

设备损坏概率采用双参数威布尔分布（Weibull Distribution）计算：

```
P(损坏) = 1 - exp(-(t / η)^β)

其中：
  t    = 设备已用年限
  η    = 特征寿命 = 预期寿命 × 1.2 × BQF
  β    = 形状参数（取决于设备类型，范围 1.5 ~ 2.8）
  BQF  = 品牌品质系数（格力 1.10 / 美的 1.05 / 海尔 1.08 / 西门子 1.20 / 松下 1.15 / 通用 1.00 / 经济品牌 0.85）
```

**老化功率修正**：设备有效功率随时间退化，采用二次衰减公式：

```
P_有效 = P_额定 × (1 + 老化率 × (已用年限 / 预期寿命)²)
```

老化率默认值为 15%，不同类型设备可配置不同的老化率。

### 4.4 数据持久性说明

- **会话内持久性**：同一浏览器中，所有数据修改（编辑信息、添加设备、缴费、发送留言等）会持久保存在 localStorage 中，关闭标签页后重新打开数据仍在
- **会话间隔离**：不同浏览器的数据完全独立，互不影响
- **初始数据恢复**：执行 `localStorage.clear()` 清除浏览器缓存后刷新页面，系统会重新从 JSON 种子文件加载初始演示数据

## 第5章 常见问题与故障排查

### 5.1 登录与账户

**Q：登录时提示"用户名或密码错误"怎么办？**

检查输入的用户名和密码是否正确。系统区分大小写，请确保键盘未开启大写锁定。用户端和管理员端使用不同的角色切换按钮，请确认已选择正确的登录角色。

**Q：忘记演示账号密码怎么办？**

演示账号密码统一为 `123456`。如仍无法登录，请清除浏览器缓存后刷新页面，系统将恢复初始状态。

**Q：可以注册新账户吗？**

可以。在登录界面点击「立即注册」进入六步注册向导，依次填写账户信息、基本信息、住房信息、设备偏好、收入信息，完成后系统自动创建账户并登录。

### 5.2 数据相关

**Q：推进月份后为什么用户端的"当前月份"没有变化？**

用户端显示的"当前月份"来自系统月份表。请确认管理员已成功执行月度推进操作。如果执行后仍显示旧月份，刷新页面即可。

**Q：账单已缴费但还显示"未缴"？**

请确认缴费操作是否完整执行（支付密码输入 → 确认）。如果卡在某一步，重新登录后再次尝试缴费。

**Q：推进月份后为什么我的设备没有产生用电记录？**

请确认该设备的状态为「正常运行」（`is_active = 1`）。已损坏的设备不会参与当月用电计算。

**Q：数据会不会丢失？**

系统数据存储在浏览器本地。以下操作会导致数据恢复初始值：清除浏览器缓存、使用浏览器的"无痕/隐私"模式、更换浏览器、更换设备。正常使用（包括关闭标签页、重启浏览器）不会丢失数据。

### 5.3 设备与报修

**Q：如何判断设备是否损坏？**

系统在每个月初（月度推进时）根据威布尔分布模型重新计算每台设备的损坏概率。当损坏概率超过 80% 阈值时，设备被自动标记为损坏。损坏设备在设备管理页面显示为半透明状态，并在维修报单页面以红色卡片展示。

**Q：报修后多久能修好？**

在演示环境中，报修工单的处理速度为即时：管理员在后台执行「派单」→「维修中」→「完成」操作后，维修费用计入用户下月账单。实际操作没有时间延迟。

**Q：维修费用如何计算？**

维修费用由管理员在「完成」维修工单时手动输入。系统不提供自动定价功能，费用金额由管理员根据故障类型自主决定。

### 5.4 知识图谱

**Q：知识图谱节点太密集看不清楚怎么办？**

可以使用鼠标滚轮进行缩放，或拖拽节点调整布局。双击已展开的大类节点可以折叠其子节点，减少画面复杂度。

**Q：为什么双击节点没有反应？**

请确认双击的是大类节点（灰色方框节点），而非设备子节点或标签节点。只有大类节点支持展开/折叠操作。此外，系统设置了 300 毫秒的单击/双击识别延迟，请在双击时保持鼠标稳定，不要移动。
