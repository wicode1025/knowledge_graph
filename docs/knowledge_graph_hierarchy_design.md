# 知识图谱层级结构设计方案

## 一、核心设计思路

采用**树状层级图谱**结构，从中心用户向外辐射展开：

```
                            ┌─────────────┐
                            │   标签节点   │ ← Level 2: 行为标签
                     ┌──────┤  节能型/高耗能 │
                     │      └─────────────┘
                     │             │
                     │      ┌─────────────┐
                     │      │  能耗等级   │ ← Level 2: 能耗等级
              ┌──────┤      │  极高/高/中  │
              │      │      └─────────────┘
              │      │            │
    ┌─────────┴──┐  │            │
    │   当前用户   │  │      ┌─────────────┐
    │  RES_0001   │──┼──────┤  用电模式   │ ← Level 2: 用电模式
    └─────────┬──┘  │      │  早峰/晚峰   │
              │      │      └─────────────┘
              │      │            │
    ┌─────────┴──┐  │            │
    │   数据节点   │  │      ┌─────────────┐
    │            │  └──────┤  标签用户群   │ ← Level 3: 同标签用户
    └─────────┬──┘         │  (可点击跳转) │
              │            └─────────────┘
              │
    ┌─────────┴──┐
    │   设备节点   │ ← Level 2: 设备
    │ 冰箱/空调/...│
    └─────────────┘
```

---

## 二、节点层级定义

### Level 0: 中心节点
- **当前用户**: 以选中的用户为中心

### Level 1: 一级分支
| 分支 | 说明 |
|------|------|
| 数据节点 | 用户的用电数据相关 |
| 标签节点 | 用户的画像标签相关 |

### Level 2: 二级节点

**数据分支**:
- 设备节点 (冰箱、空调、洗衣机等)
- 用电统计 (日均/总用电量)

**标签分支**:
- 能耗等级 (极高/高/中/低)
- 行为标签 (正常型/波动型/节能型/高耗能型)
- 用电模式 (早峰型/晚峰型/稳定型/不稳定型)

### Level 3: 扩展节点 (仅标签分支)
- 当点击某一标签时，显示**所有拥有该标签的用户**
- 这些用户节点分散在标签周围
- 点击这些用户节点 → 跳转到该用户（保留原功能）

## 三、交互设计

### 3.1 节点颜色编码
| 节点类型 | 颜色 | 大小 |
|----------|------|------|
| 当前用户 | 蓝色 #5470C6 | 最大 |
| 一级分支 | 灰色 #8c8c8c | 中等 |
| 设备节点 | 绿色 #91CC75 | 中等 |
| 标签节点 | 黄色 #FAC858 | 中等 |
| 标签用户群 | 浅蓝 #73C0DE | 较小 |

### 3.2 点击行为
1. **点击相似用户节点** → 切换为中心用户（保留原功能）
2. **点击标签节点** → 展开显示所有同标签用户
3. **点击标签用户** → 切换为中心用户
4. **点击设备节点** → 显示设备详情

### 3.3 展开/收起
- 默认显示一级和二级节点
- 点击标签节点才展开三级节点
- 再次点击标签节点可收起

## 四、数据结构

```javascript
// 图谱节点
{
  id: 'user_xxx',        // 唯一ID
  name: '用户1',          // 显示名称
  level: 0,              // 层级 (0-3)
  category: 'user',      // 类型: user/device/label/tag_users
  parentId: null,        // 父节点ID
  clickable: true,        // 是否可点击
  children: []           // 子节点
}

// 图谱边
{
  source: 'user_xxx',
  target: 'data_node',
  label: 'has'           // 关系类型
}
```

---

## 五、布局算法

采用**力导向布局 + 层级约束**:
1. 中心节点固定在中央
2. Level 1 节点围绕中心环形分布
3. Level 2 节点在对应分支方向展开
4. Level 3 节点在标签周围散开
